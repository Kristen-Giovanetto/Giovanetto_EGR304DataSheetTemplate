## Overview
The team is using servo motors and brushless DC motors to allow the device to work and to fold the clothes. Each of the team's Nano boards will be connected for the product to be developed. The block diagram allows the team to see the goal and to create a plan on how they are going to split the functions.

To get some initial formatting help, one can view ["here"](https://embedded-systems-design.github.io/EGR304DataSheetTemplate/Appendix/basic-markdown-examples/) some basic techniques.
